# ARVIS ONLINE — бот служби підтримки

Повноцінний Telegram-бот підтримки з тікетами, SQLite, адміністраторами, файлами, відповідями, закриттям, оцінюванням і персональною статистикою.

## 1. Встановлення

Потрібен Python 3.10+.

```bash
python -m venv .venv
```

Linux/Termux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

Windows:

```powershell
.venv\\Scripts\\activate
pip install -r requirements.txt
```

## 2. BOT_TOKEN

Є два способи.

### Варіант A — змінна середовища

```bash
export BOT_TOKEN="ВАШ_ТОКЕН"
python main.py
```

### Варіант B — файл `.env`

Скопіюйте `.env.example` у `.env` та впишіть токен:

```text
BOT_TOKEN=ВАШ_ТОКЕН
```

Поточний `main.py` читає `BOT_TOKEN` із середовища. Якщо використовуєте `.env`, перед запуском можна експортувати його через оболонку або додати `load_dotenv()` у верхню частину файлу.

## 3. ADMIN_IDS

Відкрийте `main.py` і знайдіть:

```python
ADMIN_IDS = [
    123456789,
    987654321,
]
```

Замініть числа на реальні Telegram ID адміністраторів.

## 4. Сервери та категорії

Сервери редагуються у словнику `SERVERS`.
Категорії редагуються у словнику `CATEGORIES`.

## 5. Запуск

```bash
python main.py
```

Після першого запуску автоматично створиться:

- `data/arvis_online_support.sqlite3` — база даних;
- `logs/bot.log` — лог бота;
- `media/` — каталог, зарезервований для локальних медіафайлів.

Telegram `file_id` зберігаються в SQLite, тому докази залишаються прив'язаними до конкретного тікета і доступні після перезапуску бота.

## 6. Основний сценарій

Гравець → створення звернення → сервер → нікнейм → номер акаунта → підтвердження → категорія → опис → файли → фінальна перевірка → тікет.

Адміністратор → нові звернення → взяти в роботу → відповідати → закрити → гравець оцінює роботу.

Одночасне взяття одного нового тікета захищене умовою оновлення SQLite: тільки один адміністратор може успішно перевести його з `new` у `in_progress`.
